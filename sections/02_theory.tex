\section{Rotated Constellation Technique}

\subsection{Related works}
Many works have been studied in the scientific literature about rotated constellation application. First proposed in DVB-T2, this technique is also proposed for Multicarrier-Code Division Multiple Access (MC-CDMA) and Underwater Acoustic Communications and Wireless Fidelity (WIFI).

In 2008, the principles, advantages and shortcoming of rotated constellation have been investigated \cite{ref6}. It has demonstrated that the rotated constellation technique allows to increase the diversity order in DVB-T2 transmission system while inducing the demapper complexity. The performance of this technique were evaluated under fading channel with and without erasure. The resulting gains vary from 0.2~dB to several dBs depending on the constellation order, the coding rate and the channel model.

During the same year (2008), the spatial diversity technique provided by rotated constellation in the second generation broadcast systems have been presented \cite{ref7}. Also, the criteria using for choosing the rotated constellation angle has been investigated and DVB-T system performance have been evaluated under the classical Rayleigh fading channel. The resulting performance improvement vary from 0.2~dB to several dB depending on the constellation order and the coding rate.

In 2009, the rotated constellation principles, the chosen angle in DVB-T2 and the general information about this system have been investigated \cite{ref8}. It has been shown that a better performance is achievable when rotated constellation is used in DVB-T2 under frequency-selective channel. Moreover, The results demonstrated that the rotated constellation performance gains are very good for low constellation orders and high code rates.

In 2013, the rotated constellation performance have been investigated using different type of Pilot Pattern (PP) \cite{ref9}. The aim of this study was to evaluate the gain achieved using various PP, a 256-QAM modulation and 32768 sub-carriers. This performance evaluation is done in the fixed scenario channels, with directional roof antenna and in a fixed position, depending on the PP scheme used.

In 2018, the authors proposed a new scheme based on the Spatial modulation orthogonal frequency division multiplexing (SM-OFDM) \cite{ref10}. This new scheme adds information elements in the transmitted SM data block consisting in choosing a constellation among the set of available rotated constellations. This new scheme brings better performance in terms of spectral efficiency but generates a higher bit error rate compared to the conventional SM-OFDM.

In the same year (2018), rotated constellation performance have been explored under under-water acoustic environment \cite{ref11}. These authors define under-water acoustic channels as being time-consuming channels that consume power and are limited in bandwidth. They propose an underwater system transmission model which includes the rotated constellation technique and emulates an underwater acoustic channel. The rotation angles adopted are the angles:
\begin{equation}
\phi = \arctan\left(1/M^{1/2}\right)
\end{equation}
These angles present several properties which make it possible to exploit the spatial diversity advantages and reduce the demodulator complexity when the rotated constellation is used. This solution brings almost the same performance than the max-log with more than 80\% reduction in overall complexity.

In 2019, rotated constellation performance have been evaluated in the DTT network of Thailand \cite{ref12}. This study was conducted in 20 transmitters network in Bangkok, Thailand with the parameters recommended by the Thai regulatory body. The adopted parameters are presented as follows: bandwidth 8~MHz, Fast Fourier Transform (FFT) Mode 16K (16384 subcarriers) Extended Mode, Pilot Pattern PP2, Guard Interval 19/128, Constellation 64~QAM, rotated constellation ON and Off, Code Rate 3/5.

In 2020, rotated constellation technique has been proposed for Non Orthogonal Multiple Access (NOMA) WIFI prototype system \cite{ref13}. Indeed, NOMA is a technique used to improve WIFI performance. The aim of the rotated constellation technique insertion is to combat phase noise which is detrimental to NOMA signals. Thus the results showed that the NOMA prototype including rotated constellation technique allows a robust reception compared to the traditional NOMA.

In the papers respectively published in 2021 and 2022, an exhaustive review on low complexity demappers proposed for DVB-T2 when rotated constellation has been presented \cite{ref14,ref15}. These authors were the first authors who present a technical comparison of complexity reduction algorithms used for two dimensional demodulator in DVB-T2.

\subsection{Principles}
The rotated constellation consists in applying a rotation angle to the classical constellation. After the classical modulation QAM, an angle is applied to the QAM constellation diagram so that each symbol uniquely bears its I and Q components (Fig.~\ref{fig:constellation}). Indeed, the classical QAM constellation implies an independence between the components I and Q of each symbol \cite{ref2}. As a result, the constellation symbols detection requires the exploitation of both I and Q components. When the classical constellation only is used, the In phase (I) component does not contain any information on the quadrature (Q) component and vice versa. In order to prevent this independence, an counterclockwise angle is applied to the classical constellation. Then, each symbol holds the unique I and Q components and can therefore be identified or detected by only one of these components \cite{ref3}.

\subsection{Advantages and shortcoming}
The main advantages of the rotated constellation are presented is this part. It is followed by the disadvantages of this technique. As previously shown in the related works, this technique provides performance gains under frequency selective channels. In particular in DVB-T2, the maximum gain is achieved when low constellation order (like QPSK) and high code rates (such as Code Rate (CR)=4/5 and CR =5/6) are used. Conversely, the gain is much reduced for constellation sizes (such as 256~QAM) and lower code rates \cite{ref16}. Rotated constellations show more gain when the percentage of erasures in the channel increases, and less gain when the percentage of erasures is low. This technique is more useful when the RF channel is faulty, causing a large percentage for the channels to fade. The exploitation of the rotated constellation in DVB-T2 gives no performance loss or gain under Gaussian channel and a gain higher than 0.7~dB under fading channel \cite{ref16}. However, this technique induces a low complexity demapping. A two dimensional demapper is required when rotated constellation is used instead of the one dimensional demapper used with the classical QAM.
